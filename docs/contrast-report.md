# Palette and contrast audit

Source of truth: `Haddar Bijoux — Palette.html`.

| Foreground | Background | Contrast |
|---|---|---:|
| ink | bg | 14.08:1 |
| ink | panel | 15.33:1 |
| inkSoft | bg | 5.31:1 |
| inkSoft | panel | 5.78:1 |
| ink | gold | 4.92:1 |
| goldText | bg | 5.80:1 |
| goldText | panel | 6.32:1 |

Gold text on ivory is 5.80:1 and on white is 6.32:1. It is used for links and small labels only where the approved owner palette supports the intended hierarchy.

All combinations used for normal text meet 4.5:1. The site uses the approved gold-text token for links and labels and keeps body copy in ink or soft ink.

The site deliberately uses this single light palette even when the device requests dark mode. No unapproved dark palette or extra color remains.
